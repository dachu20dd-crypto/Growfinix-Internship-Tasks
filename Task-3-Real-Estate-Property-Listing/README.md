# 🏠 Real Estate Property Listing Platform

## 📌 Project Overview

The Real Estate Property Listing Platform is a full-stack web application where administrators can upload property details and images while users can browse available properties.

Property information is stored in MongoDB, and property images are uploaded securely to Cloudinary.

---

## 🚀 Features

- Add Property Listings
- Upload Property Images
- View Property Listings
- Edit Property Details
- Delete Property Listings
- MongoDB Integration
- Cloudinary Integration
