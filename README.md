### Description
Developed a secure user authentication system with registration and login functionality using JWT authentication and MongoDB.

### Features
- User Registration
- User Login
- Password Hashing
- JWT Authentication
- Protected Routes
- MongoDB Integration

**Technology Stack**
- React.js
- Node.js
- Express.js
- MongoDB
- JWT
- Tailwind CSS

### Description

### Features
- Add Enquiry
- View Enquiries
- Update Enquiry
- Delete Enquiry
- PostgreSQL Integration

**Technology Stack**
- React.js
- Node.js
- Express.js
- PostgreSQL
