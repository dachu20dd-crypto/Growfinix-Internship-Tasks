# 🌍 Tour Enquiry Management Platform

## 📌 Project Overview

The Tour Enquiry Management Platform is a full-stack CRUD application where users can submit travel enquiries and administrators can manage them efficiently.

The application uses PostgreSQL for storing enquiry information and REST APIs for communication between the frontend and backend.

---

## 🚀 Features

- Add Tour Enquiry
- View All Enquiries
- Update Enquiry
- Delete Enquiry
- PostgreSQL Integration
- Responsive User Interface

---
