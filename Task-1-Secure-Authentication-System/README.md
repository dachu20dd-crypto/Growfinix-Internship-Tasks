# 🔐 Secure Authentication System

## 📌 Project Overview

The Secure Authentication System is a full-stack web application that enables users to register and log in securely using JWT authentication. User passwords are encrypted using bcrypt before being stored in MongoDB.

---

## 🚀 Features

- User Registration
- User Login
- Password Hashing using bcrypt
- JWT Authentication
- Protected Routes
- MongoDB Integration
- Responsive User Interface

---

## 🛠️ Technology Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### Authentication
- JWT
- bcrypt.js
